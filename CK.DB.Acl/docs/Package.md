Access Control Lists: the `CK.tAcl`, `CK.tAclConfigMemory` and `CK.tAclConfig` tables that grant a level to Actors on an Acl, with the well-known standard Acls.

Main types: `AclTable` (create, destroy, grant, read the grant level), `AclConfigTable`, `AclConfigMemoryTable`.

See the [README](https://github.com/signature-opensource/CK-DB/blob/stable/CK.DB.Acl/README.md).
