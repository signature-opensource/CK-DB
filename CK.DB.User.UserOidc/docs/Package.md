The OpenID Connect logins of the users: the `CK.tUserOidc` table that binds a user to its identity (the subject) for each "Oidc" scheme, the "Oidc" provider and the handlers of the commands of CK.IO.User.UserOidc.

Main types: `UserOidcTable` (the `IGenericAuthenticationProvider` of `IUserOidcInfo`), `Package`.
