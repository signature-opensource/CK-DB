# CK.DB.Auth.AuthScope

**Deprecated, without replacement**: the authorization scopes of the former OAuth providers are not used by the OpenID Connect logins ([CK.DB.User.UserOidc](https://github.com/signature-opensource/CK-DB/tree/stable/CK.DB.User.UserOidc)).

This package is a tombstone: it has no code, and a project that depends on it (directly or through another
package) fails to build with the `CKDEPRECATED` error. See the [migration guide](https://github.com/signature-opensource/CK-Stack/blob/main/Docs/Migrations/v2026.282-to-explo-cris-auth.md).
