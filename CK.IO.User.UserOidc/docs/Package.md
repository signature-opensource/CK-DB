The self-service commands of a user's OpenID Connect identities (CK.DB.User.UserOidc): `IGetOidcIdentitiesQCommand`
lists the identities of the current user (scheme suffix, claims shared by the provider, last login),
`IUnlinkOidcIdentityCommand` unlinks one (Critical level, refused while impersonating and for the user's last way to log
in).

See the [README](https://github.com/signature-opensource/CK-DB/blob/stable/CK.IO.User.UserOidc/README.md).
