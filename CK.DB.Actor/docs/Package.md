The base model of the Actors: the `CK.tActor`, `CK.tUser` and `CK.tGroup` tables, the group memberships and their procedures.

Main types: `ActorTable`, `UserTable` (with the handlers of the user name commands of CK.IO.Actor), `GroupTable`,
`ActorProfileTable`.

See the [README](https://github.com/signature-opensource/CK-DB/blob/stable/CK.DB.Actor/README.md).
