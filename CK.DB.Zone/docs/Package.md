Adds the Zones to CK.DB.Actor: the `CK.tZone` table of the Zones, Groups that contain Groups, with the well-known AdminZone.

Main types: `ZoneTable` (create, destroy, members) and `GroupTable` (moves a Group to another Zone).

See the [README](https://github.com/signature-opensource/CK-DB/blob/stable/CK.DB.Zone/README.md).
